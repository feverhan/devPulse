# 02 技术栈与开发环境

## 技术选型

| 层 | 技术 |
| --- | --- |
| 后端 | Python 3.12、FastAPI 0.115、SQLAlchemy 2.0、pydantic-settings、APScheduler、httpx、cryptography、PyMySQL（可选 MySQL） |
| 数据库 | 默认 SQLite（数据目录下 `worklog.db`），可切 MySQL |
| 前端 | Vue 3 + TypeScript、Vite 6、Element Plus、Pinia、vue-router、echarts、axios、marked + dompurify |
| 测试 | pytest、pytest-asyncio（`backend/tests/`） |

## 目录结构

```
backend/
  app/
    main.py          # FastAPI 入口、lifespan、SPA 静态托管
    config.py        # pydantic-settings 配置
    database.py      # engine / SessionLocal / Base / init_schema
    models.py        # 全部 ORM 表
    schemas.py       # Pydantic 出入参
    deps.py          # 依赖注入（require_auth 等）
    security.py      # 密码哈希、会话 cookie、令牌加密
    migrations.py    # 启动时增量建表/补列
    timeutil.py      # 业务时区时间
    routers/         # auth setup repos commits works projects reports reviews monitors dashboard settings
    services/        # 业务实现（见 03）
  tests/
frontend/
  src/
    api/             # axios 封装、接口函数、类型
    components/      # 通用组件（TrendChart 等）
    layouts/         # DefaultLayout 侧边栏布局
    router/          # 路由与守卫
    stores/          # pinia（auth、setup 等）
    views/           # 页面
    styles/ utils/
docs/
  deploy.md          # 部署与配置完整文档
  ai-coding/         # 本文件夹
scripts/             # 安装、打包、Podman 路由等脚本
```

## 本地开发命令

```bash
# 后端（仓库根目录）
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r backend/requirements.txt             # 开发加 -r backend/requirements-dev.txt
python -m uvicorn app.main:app --app-dir backend --reload --port 8000

# 前端
cd frontend && npm install && npm run dev

# 测试 / 类型检查 / 构建
cd backend && python -m pytest
cd frontend && npm run typecheck && npm run build

# 免容器单文件打包
pwsh -File .\scripts\standalone\build.ps1
```

## 编码约定

- 含中文的代码与文档文件一律 **UTF-8 不带 BOM**。
- 后端模块习惯加 `from __future__ import annotations`；注释与日志用中文；日志 logger 命名为 `logging.getLogger("worklog")` 或模块名。
- 时间统一走 `backend/app/timeutil.py`（业务时区默认 `Asia/Shanghai`），不要直接 `datetime.now()`。
- 配置读取统一经 `app/config.py` 的 `settings` 与 `services/config_store.py`（库内 `app_settings` 表），不要散落 `os.getenv`。
