# AI Coding 项目说明文档

本文件夹存放 **AI Coding 所需的项目说明文档**：给 AI 编码助手（Codex / Claude Code 等）在改动本项目前阅读的结构化说明，也用作团队的开发速查文档。

## 文档地图

| 文件 | 内容 | 什么时候读 |
| --- | --- | --- |
| [01-项目概览.md](01-项目概览.md) | 产品定位、功能模块、关键业务规则 | 任何任务开始前 |
| [02-技术栈与开发环境.md](02-技术栈与开发环境.md) | 技术选型、目录结构、本地开发命令 | 搭建环境、跑测试 |
| [03-后端架构与模块.md](03-后端架构与模块.md) | FastAPI 分层、后台任务、调度、鉴权等机制 | 改后端 |
| [04-数据模型.md](04-数据模型.md) | 全部数据表、关键约束、建表与迁移约定 | 改表、写查询 |
| [05-API接口清单.md](05-API接口清单.md) | 全部接口按模块分组 | 前后端联调、加接口 |
| [06-前端结构与设计规范.md](06-前端结构与设计规范.md) | Vue 页面组织、路由、接口封装、页面设计约束 | 改前端 |
| [07-配置与部署.md](07-配置与部署.md) | 环境变量、部署形态、打包发布 | 涉及配置、发布 |

## 使用约定

1. 动手前先读对应文档，确认结论与代码一致时再写代码；发现文档与代码不一致，以代码为准并回头更新文档。
2. 改了目录结构、表结构、接口或配置项后，同步更新本文件夹里的对应文档。
3. 仓库根目录的用户约定（前端文案规则、页面设计约束）全文收录在 [06-前端结构与设计规范.md](06-前端结构与设计规范.md)，改前端时必须遵守。
