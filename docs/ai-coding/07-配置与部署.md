# 07 配置与部署

配置的完整说明以 [../deploy.md](../deploy.md) 为准，本文件是给 AI 的速查版。

## 配置来源

优先级：环境变量 > 程序同级 `.env`（`config.py` 的 `pydantic-settings`）。单文件运行时通过 `DEV_PULSE_ENV_FILE` 指到 exe 同级的 `.env`。

## 主要环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | 数据目录 SQLite | SQLAlchemy 连接串，MySQL 示例 `mysql+pymysql://user:pass@host:3306/daylife?charset=utf8mb4` |
| `DATA_DIR` | `./data` | 数据目录（SQLite、`secret.key`、`runtime.json` 等） |
| `APP_SECRET` | 自动生成 | 主密钥：加密仓库令牌、签发会话；丢失后已存令牌解不开 |
| `APP_PASSWORD` | 空 | 访问密码，留空不启用登录 |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | 空 | OpenAI 兼容大模型，也可在界面里配 |
| `SYNC_INTERVAL_MINUTES` | 30 | 定时同步间隔（分钟，最小 5） |
| `APP_TIMEZONE` | Asia/Shanghai | 业务时区，决定日期归属与统计口径 |

运行期改配置（数据库、大模型、密码、同步设置等）走 `app_settings` 表 / `setup` 接口，多数不需要重启。

## 数据目录

`DATA_DIR` 下：

- `worklog.db`：默认 SQLite 库；
- `secret.key`：自动生成的主密钥，**随数据目录一起备份**；
- `database.url`：手动切换过数据库时记录连接串；
- `runtime.json`：实际端口（自动顺延后）。

## 部署形态速查

| 方式 | 命令 |
| --- | --- |
| Docker Compose（外部 MySQL） | `cp .env.example .env` 填 `APP_DATABASE_URL` → `docker compose up -d --build` |
| Podman（SQLite） | `podman-compose -f docker-compose.yml -f docker-compose.podman.yml up -d --build` |
| 自带 MySQL | `docker compose -f docker-compose.mysql.yml up -d --build` |
| 单容器 | `docker run -d -p 8000:8000 -v devpulse-data:/app/data worklog-reporter:1.0.0` |
| 免容器单文件 | `scripts/standalone/build.ps1` 产出 `devpulse.exe`（图形启动器）+ `devpulse-cli.exe` |

注意事项：

- 容器里 SQLite 用命名卷，Windows 绑定挂载目录可能因 WAL 建不了共享内存文件而偶发 500。
- Podman 默认网桥可能与内网网段冲突，用 `scripts/podman_lan_route.ps1` 补路由。
- 健康检查：`GET /api/health`。
